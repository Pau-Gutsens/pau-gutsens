Personal portfolio site showcasing level design, puzzle design, and technical art work.  
Built as a single-file HTML — no frameworks, no dependencies, no build step.

🌐 **[paugutsens.github.io](https://pau-gutsens.github.io/pau-gutsens/)**

## Stack

Single `.html` file with embedded assets — images are base64 encoded inline.  
No build tools, no npm, no dependencies. Open `index.html` in any browser.

Hosted via **GitHub Pages**.

---

## Local development

```bash
git clone https://github.com/PauGutsens/paugutsens.github.io
open index.html
```
